# № 19. Верные утверждения

В № 19 даны три утверждения по планиметрии, и нужно выбрать верные (иногда — единственное верное или, наоборот, неверные). Утверждения — это определения, свойства и признаки фигур из курса геометрии 7–9 классов. Ответ краткий — номера выбранных утверждений без пробелов, запятых и других символов (например, `13`), задание оценивается в **1 балл**.

## Анализ геометрических высказываний {#15}

### Что спрашивают

- «Какие из следующих утверждений верны?» — верным может быть одно утверждение или несколько.
- «Какое из следующих утверждений верно?» — верно ровно одно.
- «Какие из следующих утверждений неверны?» / «Какое утверждение неверно?» — нужно выписать номера **ложных** утверждений.

### Что нужно знать

Ниже — утверждения, которые встречаются чаще всего. В задании формулировка может немного отличаться: важен смысл, а не порядок слов.

**Треугольники**

| Медиана прямоугольного треугольника, проведённая к гипотенузе, равна половине гипотенузы. | **верно** |

**Окружность**

| Утверждение | Ответ |
|---|---|
| Касательная к окружности перпендикулярна радиусу, проведённому в точку касания. | **верно** |
| Отрезки касательных, проведённых к окружности из одной точки, равны. | **верно** |
| Вписанный угол равен половине центрального угла, опирающегося на ту же дугу. | **верно** |
| Вписанный угол равен центральному углу, опирающемуся на ту же дугу. | неверно (он в два раза меньше) |
| Вписанные углы, опирающиеся на одну и ту же дугу, равны. | **верно** |
| Вписанный угол, опирающийся на диаметр, прямой. | **верно** |
| Диаметр, перпендикулярный хорде, делит её пополам. | **верно** |
| Если расстояние от центра окружности до прямой меньше радиуса, то прямая и окружность имеют две общие точки. | **верно** |
| Если расстояние от центра окружности до прямой больше радиуса, то прямая и окружность пересекаются. | неверно (общих точек нет) |
| Если расстояние между центрами двух окружностей больше суммы их радиусов, то эти окружности не имеют общих точек. | **верно** |
| Если радиусы двух окружностей равны 3 и 5, а расстояние между их центрами равно 1, то эти окружности пересекаются. | неверно ($1<5-3$: одна окружность внутри другой) |
| Через три точки, не лежащие на одной прямой, проходит ровно одна окружность. | **верно** |
| Центр окружности, описанной около треугольника, — точка пересечения серединных перпендикуляров к его сторонам. | **верно** |
| Центр окружности, описанной около треугольника, — точка пересечения его биссектрис. | неверно (это центр вписанной окружности) |
| Центр окружности, описанной около прямоугольного треугольника, лежит на середине гипотенузы. | **верно** |
| Около любого треугольника можно описать окружность. | **верно** |
| В любой треугольник можно вписать окружность. | **верно** |
| Около любого ромба можно описать окружность. | неверно (только около квадрата) |
| В любой ромб можно вписать окружность. | **верно** |
| Около любого прямоугольника можно описать окружность. | **верно** |
| В любой прямоугольник можно вписать окружность. | неверно (только в квадрат) |
| Около любой равнобедренной трапеции можно описать окружность. | **верно** |
| Около любого параллелограмма можно описать окружность. | неверно |
| Если сумма противоположных углов четырёхугольника равна $180^{\circ}$, то около него можно описать окружность. | **верно** |
| В выпуклый четырёхугольник, у которого суммы противоположных сторон равны, можно вписать окружность. | **верно** |

> Прямая и окружность ($d$ — расстояние от центра до прямой): $d<R$ — две общие точки, $d=R$ — одна (касание), $d>R$ — ни одной.
>
> Две окружности ($R\ge r$, $d$ — расстояние между центрами): $d>R+r$ — нет общих точек; $d=R+r$ — касаются внешним образом; $R-r<d<R+r$ — пересекаются в двух точках; $d=R-r$ — касаются внутренним образом; $d<R-r$ — одна внутри другой, общих точек нет.

### Алгоритм

1. Прочитайте вопрос: нужны верные или неверные утверждения, одно или несколько.
2. Проверяйте каждое утверждение отдельно. Ищите слова-ловушки: «любой», «всегда», «каждый», «только», «равны» вместо «пропорциональны», «равна» вместо «равна половине».
3. Попробуйте найти контрпример — фигуру, для которой утверждение не выполняется. Удобные контрпримеры: прямоугольник (не ромб), ромб (не прямоугольник), равнобедренная трапеция, тупоугольный треугольник. Одного контрпримера достаточно, чтобы утверждение было неверным.
4. Сверьте с формулировкой из учебника: не перепутаны ли условие и вывод, не пропущено ли важное условие («угол **между** ними», «не лежащие на одной прямой», «у параллелограмма»).
5. Запишите номера подряд без пробелов, для надёжности — в порядке возрастания.

### Типичные ошибки

- Путают утверждение и обратное ему: «диагонали ромба перпендикулярны» — верно, а «четырёхугольник с перпендикулярными диагоналями — ромб» — неверно.
- Не замечают пропущенное условие: «две стороны и угол» вместо «две стороны и угол между ними».
- Выписывают номера верных утверждений, когда спрашивают про неверные.
- Ставят в ответе запятые, пробелы или точки.
